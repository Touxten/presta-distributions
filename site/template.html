LE BON RÉFLEXE

Téléchargez.
Vérifiez. Installez.

Téléchargez le ZIP et son fichier SHA256SUMS depuis la même release. Comparez ensuite l’empreinte avant de l’utiliser.

Le XML contient les sommes de contrôle utilisées par Update Assistant. Il ne remplace pas la vérification SHA-256 du téléchargement.

● ● ● VÉRIFICATION LOCALE

# Linux — dans le dossier du ZIP

sha256sum prestashop_{{LATEST}}.zip

# macOS

shasum -a 256 prestashop_{{LATEST}}.zip

# PowerShell

Get-FileHash .\prestashop_{{LATEST}}.zip -Algorithm SHA256
Comparez le résultat à la ligne correspondante dans SHA256SUMS.

Communautaire. Transparent. Indépendant.

presta.zip est une initiative indépendante de Touxten, non affiliée à PrestaShop. Ces archives sont des compilations communautaires ; elles ne sont pas des binaires officiels publiés par PrestaShop.

Ces archives sont compilées à partir du code source du dépôt officiel PrestaShop, en utilisant le tag correspondant à chaque version. Les liens vers les sources et les empreintes SHA-256 sont disponibles pour chaque téléchargement.
